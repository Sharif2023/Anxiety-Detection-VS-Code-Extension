# Programming Anxiety Detector VSCode Extension

A research tool for detecting programming anxiety through behavioral data analysis.

## Features

- **Real-time Data Collection**: Tracks keystrokes, activity patterns, errors, and code patterns
- **Anxiety Metrics**: Calculates anxiety scores based on behavioral patterns
- **Live Dashboard**: Visualize anxiety metrics and programming behavior
- **CSV Export**: Export collected data for research analysis
- **Configurable Settings**: Customize data collection parameters

## Data Collected

- Keystroke patterns and timing
- Active/idle time ratios
- File statistics and focus patterns
- Error frequency and resolution time
- Code patterns (functions, loops, bug fixes)
- Undo/redo operations
- Compilation attempts

## Installation

1. Download and install the extension
2. Restart VSCode
3. The extension will automatically start collecting data
4. Use the command palette to access the dashboard (`Ctrl+Shift+P` → "Show Anxiety Dashboard")

## Privacy

All data is stored locally and only exported when explicitly requested. No data is transmitted to external servers.

## Research Use

This extension is designed for academic research on programming anxiety. The collected data can be used to study correlations between programming behavior and anxiety levels.
